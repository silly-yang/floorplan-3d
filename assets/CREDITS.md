# 素材來源與授權

本目錄的貼圖與模型皆為 **CC0 1.0（公眾領域）**，可商用、免標示；此清單供追溯來源。

- 貼圖原檔為 1K JPG；為了首頁下載量，部分檔案以較低 JPEG 品質重新壓縮，粗糙度貼圖縮為 512 px。
- 各貼圖資料夾的 `thumb.jpg` 是材質選單用的 128 px 縮圖，由原檔縮小而成。
- ambientCG 的壓縮包只保留 Color、NormalGL、Roughness 三張。
- Quaternius 模型檔名已改為英文小寫（原名見下表）。
